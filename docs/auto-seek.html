New · a Stash plugin from Curator

Skip the intro. Every scene.

Auto Seek finds where the action starts in each scene and jumps straight there. Tap Skip intro on the player, or let it skip on its own. Your Stash server works it out in a few seconds when you open a scene, or ahead of time in the background.

Install Auto Seek See how it finds the start

How it finds the start

No chapter markers needed. An image model that knows what an intro looks like reads a handful of frames and homes in, like you would with the scrubber, only faster.

Glance

It scores the 12 points Stash's own preview samples, spread across the scene, and stops as soon as the action is clearly on.

Zoom

Where the scores jump, it scans the stretch in between, frame by frame, until one is clearly past the line.

Pinpoint

A few rounds of halving the gap land it within seconds. The player jumps a moment before that, for a smoother way in.

Made for how you actually watch

One tap, or none

Skip intro sits on the player while there's an intro to skip. Turn on Skip automatically and scenes that start from the beginning jump there by themselves.

Your call wins

Disagree? Pause where it really starts and tap the flag. That scene starts there from now on, through every model update, and Undo is one tap away.

Optionally ready ahead of time

Optionally, a background task works through your library, newest first, and new scenes are picked up as a scan adds them, so starts are ready the moment you open a scene.

Stays on your server

Frames are cut by Stash's own ffmpeg and scored right there. Nothing about your library is uploaded; the model is downloaded once and checked against its checksum.

See what it saw

A small chart above the seek bar shows every frame it scored and the start it picked, so you can tell at a glance why it jumped where it did. One setting hides it.

Runs where Stash runs

Docker on x86-64 and ARM (including 32-bit), Linux, Windows and Apple Silicon Macs. Nothing extra to install: the plugin fetches what your server needs. The ARM, Windows and Mac builds are new, so tell us how they do.

Install

Three steps, then just press play

  1. 1
    In Stash, open Settings → Plugins → Available Plugins → Add Source and add Curator's plugin source:
    https://mrx-31415.github.io/stash-curator/index.yml
  2. 2
    Install Auto Seek and reload plugins. It downloads its image model (89 MB) and a runtime for your server (8–80 MB) in the background, once.
  3. 3
    Open any scene: Skip intro appears on the player. To have every scene ready ahead of time, run Find start points under Settings → Tasks.

Requires Stash v0.31 and the python Stash already uses for plugins. Auto Seek works on its own; you don't need Curator. Read the guide for settings and troubleshooting.

Honest about the misses

Auto Seek is new and was tuned and tested on one library, so treat its accuracy as a first impression. There, about 4 in 5 picks landed within a minute of the start a person chose by hand. It judges single frames, so:

  • a slow-burn opening, or people still dressed when things get going, can make it start a little late;
  • undressing or an interview without action can make it start early.

When it's wrong, the flag fixes that scene for good.

Auto Seek's model is a tuned version of LAION's CLIP ViT-B/32, hosted at huggingface.co/mrx-31415/auto-seek, and runs on ONNX Runtime. The demo above uses footage from Big Buck Bunny (CC BY 3.0, © Blender Foundation).
